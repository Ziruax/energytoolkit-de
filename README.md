# EnergyToolkit – Stromkostenrechner für Deutschland

[EnergyToolkit](https://energytoolkit.de/) ist eine kostenlose deutsche Sammlung von 66 Stromkostenrechnern: Stromkosten pro Tag, Monat und Jahr berechnen, ohne Anmeldung, ohne Tracker, direkt im Browser.

## Formel

Stromkosten = Verbrauch in kWh × Arbeitspreis in Euro pro kWh, plus Grundpreis × Monate.

Beispiel: 2.920 kWh × 0,37 Euro = 1.080,40 Euro im Jahr, zuzüglich Grundpreis.
